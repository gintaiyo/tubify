# Tubify

A small scaled spotify based website which uses yt-dlp api

![License](https://img.shields.io/badge/license-MIT-blue.svg) ![Version](https://img.shields.io/badge/version-1.0.0-green.svg) ![Node](https://img.shields.io/badge/node-%3E%3D14.0.0-brightgreen.svg)

## Features

- No Buffering 
- Ad Free
- Easy to Use

### Tech Stack

- **Node.js**
- **EJS**
- **CSS**
- **Vanilla JS**

## Installation

```bash
git clone https://github.com/gintaiyo/tubify.git
cd tubify
npm install @distube/ytdl-core ejs express youtube-sr yt-dlp-exec
```

## Usage

```bash
node server.js
```
